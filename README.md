VIAR MOTOR INDONESIA — WEBSITE SATU HALAMAN

Cara menjalankan:
1. Ekstrak ZIP ke satu folder.
2. Buka index.html dengan browser atau gunakan Live Server di VS Code.
3. Semua gambar website disimpan secara lokal di folder img/.
4. CSS dan JavaScript tetap disimpan terpisah di folder css/ dan js/.

Catatan revisi:
- Sumber gambar eksternal pada HTML, CSS, dan JavaScript telah diganti dengan file lokal.
- Gambar produk dan ilustrasi spesifikasi dipilih dari aset yang diberikan, sesuai konteksnya (kendaraan niaga, pertanian, adventure, listrik, mesin, dan pengisian daya).
- Struktur halaman, layout, warna, animasi, serta fungsi website dipertahankan.
- Font Google Fonts dan ikon Font Awesome masih memakai CDN eksternal; yang diminta untuk dilokalkan pada revisi ini adalah gambar.
- Harga dan spesifikasi produk tetap mengikuti data ZIP asal dan perlu dikonfirmasi dengan katalog resmi VIAR sebelum digunakan sebagai informasi penjualan resmi.
